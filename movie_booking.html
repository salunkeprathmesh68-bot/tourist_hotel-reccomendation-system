C++ Object-Oriented Programming (OOP) Architecture

Detailed breakdown of how every required OOP concept is implemented in the underlying C++ source code (main.cpp).

1. Encapsulation

Classes like Movie, Theatre, and Booking have all attributes declared as private, accessible strictly through getters and validation methods.

2. Inheritance & Polymorphism

Base class Seat with pure virtual function virtual double calculatePrice() = 0; overridden dynamically by RegularSeat and PremiumSeat.

3. Abstraction & Payment Interface

Abstract base class PaymentGateway with virtual bool processPayment() = 0; implemented polymorphically by UPIPayment, CardPayment, and NetBankingPayment.

4. Aggregation & Strategy Pattern

Class Booking aggregates vector<SnackItem> (F&B orders), while promo discounts implement a strategy pattern via dynamic discount resolvers.
